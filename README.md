# IDEB and Income Analysis (Brazil)

This project explores the relationship between municipal income and educational performance
(IDEB) in Brazil using public datasets.

## Research Question
Is there a correlation between average municipal income and IDEB scores?

## Data Sources
- Municipal data (IBGE)
- IDEB data (INEP)

## Status
Initial exploratory analysis.
## Methodological Note
Due to temporary access limitations to official IBGE and INEP APIs, 
income and IDEB values are currently simulated for methodological demonstration.
All analysis code is structured to be directly reusable with official datasets.
## Preliminary Interpretation (Simulated Data)

This exploratory analysis demonstrates the methodological approach to
investigating the relationship between income and educational performance.
Due to the simulated and limited dataset, no substantive conclusions can be drawn.
Future work will replace simulated values with official IBGE and INEP data.
